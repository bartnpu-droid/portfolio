Free shipping progress bar, gift options at checkout, product badges and scent notes for WooCommerce block stores.

== Description ==

Made for the Ombra demo store, written to work in any WooCommerce store that uses the Cart and Checkout blocks.

* **Free shipping progress bar.** In the Cart and Checkout blocks, in the mini-cart drawer and anywhere you place the "Free shipping progress" block (an announcement bar, a product page). One calculation on the server, sent with the Store API cart, so every place shows the same amount and updates after every cart change.
* **Gift options at checkout.** "This order is a gift" and a gift note, through the Additional Checkout Fields API. The note shows only when the box is ticked, has a length limit, and appears in the order screen, emails, the order confirmation and a "Gift" column in the orders list.
* **Badges and scent notes.** An "Ombra details" tab on each product (badge, top/heart/base notes, burn time, materials) and two blocks to show them.

Settings: WooCommerce → Settings → Ombra.
