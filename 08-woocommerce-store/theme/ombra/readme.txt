Block theme for Ombra, a made-up candle and home fragrance brand, built for WooCommerce.

== Description ==

Templates for the home page, shop, categories, product page, cart, checkout and pages; patterns for the home page sections; colours, fonts and spacing in theme.json. Works with the Ombra Store Tools plugin (free shipping bar, badges, scent notes) and without it.
